# Worked example: a document importer

This is a synthetic example of the records, not a reported software build or test run. Its observations illustrate how to record results; they are not historical Ground Zero evidence.

The parent outcome is a usable document importer. Its parser, preview and library writer have different responsibilities. A parser can finish while integration and user acceptance remain open.
